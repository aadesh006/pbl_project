KERNIX

REAL-TIME OPERATING SYSTEM

A lightweight kernel built for direct hardware interaction, interrupt-driven execution, and modular 32-bit protected mode operation. Designed for deterministic behavior in embedded and resource-constrained environments where every clock cycle counts.

0xB8000 Shell / VGA

Boots via custom bootloader at 0x7C00, transitions to 32-bit protected mode, configures GDT/IDT and PIC interrupt chains, loads hardware drivers, and enters a continuous IRQ-driven execution loop.
